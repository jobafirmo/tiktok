# Escopo de trabalho

Este projeto está limitado a `jobafirmo/tiktok` e à operação da campanha no TikTok Ads.

## Restrições do titular

- Alterações no GitHub são autorizadas exclusivamente neste repositório.
- Não alterar IASIS, LançaMais, LanceCerto, seus sites, aplicativos, Workers, bancos ou ambientes.
- Não instalar Pixel nem publicar código nos sistemas citados.
- Não criar integrações, workflows de implantação ou scripts que alterem outros projetos.
- Não publicar ou ativar anúncios, iniciar gastos, configurar pagamento ou aumentar o investimento sem autorização expressa.
- Usar somente textos técnicos e comerciais aprovados pelo titular.
- Preservar configurações corretas já concluídas.
- Manter uma campanha, um grupo e cinco anúncios individuais como estrutura inicial, salvo nova decisão do titular.

## Dados

O repositório é público. Armazenar aqui somente documentação, código autorizado e modelos vazios.
Não versionar credenciais, tokens, dados de leads, documentos pessoais, exportações preenchidas ou informações privadas de faturamento.
IDs reais devem ser preservados como texto nos arquivos privados de trabalho.

## Relato de resultados

Distinguir o que foi configurado do que foi apenas planejado.
Não apresentar métricas fictícias, cliques como cadastros, leads como clientes ou testes como assinaturas pagas.
Não declarar vencedor quando a entrega ou a quantidade de resultados não permite comparação.
